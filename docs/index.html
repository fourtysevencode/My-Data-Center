One-time setup


The game is served through a Cloudflare Tunnel. Do this once and you can connect any time.



    

  1. 

    Install cloudflared
    

    




    

    

    $ brew install cloudflared
    

    

    

    > winget install --id Cloudflare.cloudflared
    

    

    

    $ curl -L -o cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x cloudflared && sudo mv cloudflared /usr/local/bin/
    

    Or grab a package for your distro from Cloudflare's downloads page.
    

    

    2. 


  2. 

    Add this to your SSH config
    

    The file is ~/.ssh/config (on Windows, C:\Users\<you>\\.ssh\config). Create it if it doesn't exist.
    

    Host play.ronakbuilds.tech
  ProxyCommand cloudflared access ssh --hostname %h
    

    On macOS or Linux you can append it in one go:
    

    $ printf 'Host play.ronakbuilds.tech\n  ProxyCommand cloudflared access ssh --hostname %%h\n' >> ~/.ssh/config
    

    3. 


  3. 

    Connect
    

    $ ssh play.ronakbuilds.tech
    

    No SSH key or password needed. The game has its own login. Pick a username and you're in.
    

    4. 








How to play


Start with $500. Buy servers. Watch the money roll in every second you're connected.








1 Name your data center

2 Buy servers


Type a server number and press Enter. Each extra copy of the same server costs 15% more.

See what you own and what it earns. M goes back.

Troubleshooting




Permission denied (publickey)


The SSH config entry is missing or misspelled, so you reached the host machine instead of the game. Add it, run ssh-keygen -R play.ronakbuilds.tech, and connect again.


remote error: tls: internal error


Your computer has an old DNS record cached. On macOS run sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder.


cloudflared: command not found


cloudflared isn't installed or isn't on your PATH. Redo step 1.


Garbled screen


Make your terminal at least 80×24 and reconnect.
